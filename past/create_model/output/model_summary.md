# 決定木モデル - モデルサマリー

## 1. モデル概要

**モデル名:** Decision Tree Classifier (決定木分類器)  
**目的:** 格闘ゲームのコントローラー入力パターンからプレイヤー（ユーザー）を判定する

---

## 2. 目的変数（従属変数）

| 変数名 | 説明 | 値 |
|--------|------|-----|
| **user** | プレイヤー名 | 9ユーザー：jin, keita, kotaro, akira, ryo, nakamura, yamaguti（その他ID値） |
| 分類数 | - | 141クラス（メインユーザー7名 + ノイズデータID約134） |

---

## 3. 説明変数（独立変数）

合計28個の特徴量を使用

### 3.1 ボタン入力
- **A** - パンチボタン
- **B** - キックボタン
- **RB** - 右ショルダーボタン
- **LB** - 左ショルダーボタン
- **RT** - 右トリガー
- **LT** - 左トリガー
- **SELECT** - セレクトボタン
- **START** - スタートボタン

### 3.2 方向入力
- **Up, Down, Left, Right** - 方向キー
- **UpLeft, UpRight, DownLeft, DownRight** - 斜め方向

### 3.3 コマンド検出
- **Shoryuken** - 昇竜拳コマンド検出（→↓↘ + パンチ）
- **Hadoken** - 波動拳コマンド検出（↓↘→ + パンチ）

### 3.4 ボタン組み合わせダミー
- **Right_Jump** - 右 + ジャンプ
- **Left_Jump** - 左 + ジャンプ
- **Right_Kick** - 右 + キック
- **Left_Kick** - 左 + キック
- **Punch_Kick** - パンチ + キック
- **Jump_Punch** - ジャンプ + パンチ

### 3.5 動画処理特徴量
- **standing_right** - プレイヤーが画面右側に位置（StateXの正負から推定）
- **standing_left** - プレイヤーが画面左側に位置
- **body_right** - キャラクターが右向き
- **body_left** - キャラクターが左向き

## 6. データ分割方法

**方法:** 同一対戦ペアでの縦分割

- **訓練データ:** 各対戦ペアの1試合目（match_number = 1）
- **テストデータ:** 各対戦ペアの2試合目（match_number = 2）

**利点:**
- 同じプレイヤーペアの異なる試合でモデルを評価
- 異なる時間軸での予測性能を測定

## 9. 考察

### 9.1 モデルの有効性
- **kotaro と jin** のユーザーは特徴的なプレイスタイルを持ち、約53%の精度で識別可能
- **キックボタン(B)** の使用パターンが最もユーザー識別に有効
- **プレイヤー位置(standing_right)** が6番目に重要な特徴で、ゲーム配置も予測に寄与

### 9.2 改善の可能性
- 特殊コマンドが検出されないため、コマンド検出ロジックの改善が必要
- サンプル数が少ないユーザー（nakamura, yamaguti等）の精度が低い
- より詳細な動画処理特徴量（骨格検出等）の追加で精度向上の可能性

### 9.3 実用性
- **ハイブリッド入力分析:** プレイスタイルの特徴抽出に有効
- **ユーザー検証:** 特定のユーザー検出用途での活用可能
- **ゲーム解析:** プレイヤーの傾向分析に有用
